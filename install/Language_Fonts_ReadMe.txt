Skynet Language Fonts (MIT License for this ReadMe, Copyright (c) OakBarn Brewery 2026)

These are web fonts for showing a Help language whose letters a screen may not have: Chinese (Simplified), Japanese, Korean, Thai
and Hindi (Devanagari). They are Google Noto Sans, Regular only, under the SIL Open Font License 1.1 (each folder has its OFL.txt).
The fonts are never sold on their own.

Phones, Windows PCs and Macs already have these letters, so most Brains never need this. It helps a screen plugged into the
Raspberry Pi Brain itself, which may show empty boxes for these languages.

Windows: run Skynet_Language_Fonts_Setup_<version>.exe. It only ADDS: a font already there is never changed, and nothing is deleted.
Mac, Linux, Raspberry Pi: unzip Skynet_Language_Fonts_<version>.zip over the folder Skynet Brewer is in (the one with server.js),
so these folders land in its fonts folder. Then press F5 in the panel.

Only the Help pages and the balloons (Hover Help) use them. Help 242 tells more.
