# Help in French

The Help can be read in **English** or in **French** (Français). Only the Help is in French: the screens, buttons, labels, menus and messages of the panel stay English, always.

## Picking the language

1. Open Help (the yellow **?** next to **☰ Menu**, or **Help** on the Menu Bar).
2. At the top of the page list, pick **🌐 Français** in **🌐 Help language**. Pick **🌐 English** to go back.

The browser remembers the choice, so Help opens in the same language next time on that PC, phone or tablet. Each browser has its own choice: one person can read Help in French while another reads it in English.

## What is in French

- Every Help page, with the same pages, parts, pictures and links as the English Help.
- The names of buttons, boxes and menus stay **in English, exactly as on the screen**, so a French page says to press **Save Build**, the same words you see on the button.
- Names of Devices, Widgets, Tabs and Processes, and Process code, are never translated.

## Notes on a French page

- **Not translated yet:** a page that has no French page yet shows the English page, with a note at the top.
- **May be out of date:** when the English page was changed after its French page was made (for example an Admin edited it), a note at the top says so, with a link to the English page.
- **Machine translation:** the French pages were made by machine translation. A note at the end of each page says so. If in doubt, the English page is the one that counts.

## For Admins

**✏ Edit page** edits the page in the language that is showing: in French it edits the French page. The French pages are the files in `help/fr/` on the Brain, with the same file names as the English pages in `help/`.
