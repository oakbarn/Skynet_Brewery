# Beer money pop-up

About once a month, each phone or computer shows a small pop-up asking for a few dollars of beer money for Fritz, who builds the panel. It never shows while a Process is running (other than ones that start with the server), while you edit a tab, or over another window.

The buttons:

- **Buy Fritz a beer** opens PayPal. Donations go to Fritz's PayPal account; this is built in and cannot be changed.
- **Maybe later** asks again after the usual wait.
- **Already donated** waits longer before asking again.

An admin can change it in **Settings > Beer money pop-up**: turn it off, change the message or button text, set how many days between pop-ups, and tap **Show it now** to see it.
