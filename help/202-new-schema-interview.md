# The New Schema Interview

As soon as **Add new Schema** has made your new Schema and loaded it, the **New Schema Interview** opens. It asks a few short questions about the new Schema, one page at a time. The steps are listed across the top, so you always see where you are.

- **Next ▶** keeps an answer as it is and goes on. **◀ Back** goes back a page.
- **Nothing is changed until ✔ Finish.**
- **Close** (or **✕**) stops the interview. The new Schema is kept as it was made; you can change all of this later.
- **✔ Finish** and **Close** take you to the new Schema's first Tab, not back to the Schema page.

## The pages

1. **About**: the **Name** (already filled in) and **What is it for?**, one line such as *Keg Cleaning* or *Hot Side, 10 gallon*. It shows in the Schema list on the **☰ Menu > Schema** tab. You may leave it blank.
2. **Boards**: the boards (Interfaces) the new Schema has, and the real boards from your other Schemas. Tick each one this Schema uses too. To add a board no Schema has yet, switch on **➕ Add a New board after Finish**: after **✔ Finish** the **Add Interface** pop-up opens, and after its **Save** the Interfaces page shows the new board. See [Interfaces](76-interfaces).
3. **Tabs**: a box for each Tab, and **➕ Add New Tab** for another one. In each box:
   - **Tab name** (for example *Main* to *Brew House*).
   - **What is it for?**: **Brewing (Brew House)**, **Fermentation**, **Cleaning**, or **Other** (any Tab of your own: you name it in Tab name).
   - **Level** (Brewing only): how you brew on this Tab, from **Stove Top (Extract)** to **All Grain with Mash Tun (3 Vessels)**. It starts on your **Skynet Brewer Level**, the Level you picked last time (All Grain with Mash Tun the first time).
   - **Equipment Profile**: **None** (add one later on **☰ Menu > Equipment Profile**), **➕ Create New** (the Equipment Profile Interview opens after Finish, see [The Equipment Profile Interview](196-equipment-profile-interview)), or a profile you already have. Only the profiles for what the Tab is for are listed. Any number of Tabs can start from the same profile.
   - **Import** (with a profile you have): **Import All** puts a copy of the profile's whole Default Layout on the Tab. **Import Vessels** puts only its vessels and equipment, with their fittings. **Import Manifold** puts only the valves, fittings and pipes between the vessels. The profile's numbers are copied too. After that the Tab keeps no link to the profile: a change on either one never changes the other.
   - **Import Processes**: a tick for each Skynet Process of that kind and Level (a Stove Top has no Mash). Ticked ones are set in **☰ Menu > Brew Process**; an unticked one is left out.
4. **Done**: what will be kept. Press **✔ Finish**.

**A Skynet Schema Template** or **an Equipment Profile** has already asked about the boards, Tabs and equipment, so they get only **About** and **Done**.

Units (US or Metric) are not asked: they are a Panel setting, the same for every Schema (**☰ Menu > Default settings**).

See also [Step by Step: Add a Schema](188-step-by-step-add-a-schema).
