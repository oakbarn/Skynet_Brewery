# Shortcut keys

These keys work in **every text and string box** in Skynet Brewer: Properties dialogs, Labels, Texts, Names, the String
Entry Dialogs (the red ⬆ Up Arrow, Rule 18.1), the Process editor and Schema.json. (Fritz, 2026-11-02, Rule 2.32)

## Skynet keys

| Windows and Linux | Mac | What it does |
|---|---|---|
| **Shift + Enter** | **Shift + Enter** | Types `\n`, the new line code. The text goes onto a new line where it is shown. |
| **Ctrl + B** | **⌘ + B** | Bold. With words picked, puts `\b` before and after them. With nothing picked, types `\b\b` with the cursor in between, so you type the bold words there. |
| **Ctrl + Shift + D** | **⌘ + Shift + D** | Types **°F** or **°C**, whichever **Temperatures** is set to on the ☰ Menu > **Default** tab. |

`\n` and `\b` are Rich Text Embedded Codes: see [Text boxes](49-text-boxes) and [Codes inside text](22-process-language).
Everything these keys type can be taken back with Undo, like any other typing.

## Common keys

| | Windows and Linux | Mac |
|---|---|---|
| Copy | Ctrl + C | ⌘ + C |
| Cut | Ctrl + X | ⌘ + X |
| Paste | Ctrl + V | ⌘ + V |
| Paste as plain text | Ctrl + Shift + V | ⌘ + Shift + V |
| Undo | Ctrl + Z | ⌘ + Z |
| Redo | Ctrl + Shift + Z or Ctrl + Y | ⌘ + Shift + Z or ⌘ + Y |

- Every Skynet text box holds plain text, so a normal Paste is already plain text. Safari has no ⌘ + Shift + V of its
  own, so Skynet does it there (Safari may show a small **Paste** button to tap first).
- **Ctrl + Y / ⌘ + Y** is Redo inside a text box. Outside a text box the browser keeps its own use for it (on a Mac, ⌘ + Y
  opens History).
- Plain **Enter** still does what it did before (in a one-line box it often presses OK or Save).
- Phones and tablets with no keyboard do not have these keys; type `\n` and `\b` by hand.
