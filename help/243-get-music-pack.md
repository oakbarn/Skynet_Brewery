# Get Music Pack

The **Skynet Music Pack** is a set of public domain marches and bugle calls, for example **First Call**, **Mail Call**, **Taps**, **Semper Fidelis** and **The Stars and Stripes Forever**. Use them in an Alarm, a Sound Player or a Process like any other sound.

It is **not** in the Setups, so the Setups stay small. **☰ Menu > Get Music Pack** copies it onto your Brain, into `media/sounds/Skynet_Music`.

- It works the same on a Raspberry Pi, Windows, Mac or Linux. Nothing to install: the Brain does the downloading.
- **No GitHub account is needed.** The Brain only has to be on the internet.
- **A sound you already have is never changed, your own sounds are never touched, and nothing is ever deleted.**
- Admins only.

## How to use it

1. Open **☰ Menu > Get Music Pack**. It asks GitHub straight away.
2. You see how many sounds the pack has, and a list of the ones this Brain does not have yet, with their sizes.
3. Press **Get N sounds**. When it is done, the new sounds are in every sound list.

Press **Check GitHub** to ask again. If everything is already here, it says **Nothing to get**.

## Good to know

- Each sound is checked against GitHub's own size and fingerprint before it is saved, so a broken download never lands. If one fails, it is listed with the reason; press **Check GitHub** and get it again.
- The Music Pack sounds are ordinary sound files. You can copy one, rename it or use it as your own sound.
- If GitHub says **too many requests**, wait an hour.
- The sounds that come with Skynet itself are in [The Skynet pictures and sounds](183-skynet-media-setup). Who made each piece is in the Media credits of the Skynet README.
