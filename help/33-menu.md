# The ☰ Menu

The **☰ Menu** button is at the top right of the **Tabs** page, where the Edit layout box used to be. Press it to see its choices. The same ☰ Menu button is also on almost every window that pops up, and on the Menu Bar of every other page, see [The ☰ Menu everywhere](51-menu-everywhere). (The top line of the panel with Processes, Settings, Help ... is the Menu Bar, see [The Menu Bar](40-menu-bar).)

- **Show Top Line** / **Hide Top Line**: the Top Line of the panel is hidden on the Tabs page; this brings it back. See [The Menu Bar](40-menu-bar).
- **Process Editor** (only while it is open): every button of the Process Editor, from New and Save to Stop all and the Colors switch, each doing the same as its button. See [The Process editor](30-process-editor).
- **🌐 Help**: **English** and **Français** in a row; one click picks the language of the Help and the balloons. Until a third language is on the Brain, an Admin also sees **➕ Add a Language**, which opens Help > 🌐 Languages (see [Help in any language](242-help-in-any-language)). Once one is added, it is the last box, written in its own letters.
- **Edit layout** is not on the ☰ Menu: it is the 🛠 **Build** icon on the Menu Bar (see [The Menu Bar](40-menu-bar)).
- **🗂 Schema**: the Schema dropdown, the same one as on the Top Line. Pick a Schema and it loads (it warns you first when Processes are running). **Add new Schema ...** and the other Schema jobs are at the end of the list. See [Switching and cloning Schemas](48-schema-switching-and-cloning).
- **🧪 Switch to Simulator** (Admins, only while the Real boards are used). In Simulator mode the 🧪 Simulator balloon on the Menu Bar switches back. See [Simulator or Real boards](77-simulator-or-real-boards).
- **🐞 Report a Bug** (everyone): tell OakBarn Brewery about a bug, on GitHub or by email. See [Report a problem](205-report-a-problem).
- **⭐ Request a Feature**: a Patron perk.
- **Last picked**: a copy of the last ☰ Menu choice you picked, so one click takes you back to it. Each browser remembers its own.
- Interfaces (boards) and Add Interface are under **Pages > Devices** at the end of the list.
- The **Menu tabs**: Zoom (number 1 to start with), Default settings, Equipment Profile, Vessel Templates, Equipment Templates, Fitting Templates, Default Layout, Mash Profile, Boil Profile, Tab Profile, Valve Profile and Pump Profile.
- **File Move Utility** (Admins) opens the File Move page. See [File Move](32-file-move).
- **Recipe** and **Fermentation** are greyed out. They are coming in the next stages.
- **Schema**: the Schema dropdown (the same one as on the Menu Bar), every Schema on the Brain with **Load** and **Clone**. See [Switching and cloning Schemas](48-schema-switching-and-cloning).
- **About** (always at the top of the Menu; it can't be moved in the Order list): who is signed in, **Sign out**, the Schema dropdown and the Schema version. See [About and Schema versions](42-about-and-schema-versions).
- **Pages** (at the end): every page of the Menu Bar, and under each page (marked ↳) its parts: your screen Tabs, Interfaces (boards), Users, MQTT and voice, Backups ... Pick one to go straight there. See [Every screen in the ☰ Menu](67-every-screen-in-the-menu).

## Menu tabs

A Menu tab only shows once you pick it. It opens next to your screen tabs, with a ☰ in front of its name, and fills the space where the tab drawing is.

- Press a screen tab (Brewery, Equipment ...) to go back to your tabs. The Menu tabs you opened stay up there, so one press takes you back.
- Press the **✕** on a Menu tab to close it.
- Every Menu tab also has **Close** and a boxed **✕** at its top right corner. Either one closes the Menu tab you are looking at. The Help page and the File Move page have them too; there they take you back to where you were.
- The Top Line always shows on a Menu tab (only your own Tabs hide it, see [The Menu Bar](40-menu-bar)).
- If a Menu tab has changes that are not saved, the panel asks before closing it or switching away.
- **✔ Saved:** when you press **Save** and stay on the same screen (a Menu tab, Settings, Default settings, a profile ...), a **✔ Saved** box shows in the middle of the screen for 2 seconds and goes away on its own. There is nothing to click (Skynet Rule 2.54). Every other short note shows in the same big box in the middle of the screen: blue for information, red for a warning or a problem.
- **Delete, Save, Undo, Close and ✕** sit together, in that order, frozen in the upper right corner of Default settings, the Equipment Profile, the Recipe and every profile tab (Pump, Valve, Tab, Mash, Boil, Water). **Save** saves and the tab stays open. **Undo** goes back to the last Save and the tab stays open (it takes the place of Cancel). **Close** (and the boxed ✕) closes the Menu tab; if there are changes that are not saved, Skynet asks first (Skynet Rule 2.54).

Everyone can look at the Menu tabs. Only an Admin can change them (an Operator can lock and unlock the Equipment Profile).

**The Default tab is now called Default settings** (2026-11-07). It holds only what a **new** thing starts with (Skynet Rule 2.42). See [Default settings](155-default-settings).

## The Default tab

**Every default is set here: what a new thing starts with.** What a new Recipe starts with: the Units, the Batch size, the Equipment Profile, the Mash Profile and the Boil Profile (each one can be changed in the Recipe itself). The Tab Profile a new tab gets (the Valve and Pump Profile a new one starts with is the one marked Default in its own list). **Labels** and **Text Boxes**: the Defaults of every text box (see [Text boxes](49-text-boxes)). New User Templates and Schemas. Press **Save**.

What changes things already made, or how the whole panel works, is in **☰ Menu > Default settings** ([Settings](09-settings)): the Top Line ([The Menu Bar](40-menu-bar)), **Sound**, **On startup** ([Zoom and Full screen](41-zoom-and-full-screen)), **\L Rich Text Code Size** ([Rich Text Embedded Code](90-rich-text-embedded-code)), Hover Delay, Phones and tablets ([Phones and tablets](45-phones-and-tablets)), Hop alerts and the **Order of the Menu**.

**Sound** (in ☰ Menu > Default settings):

- **Sound on**: the same as the sound button at the top of the page. It turns sound on or off on this screen right away, and is not saved.
- **Turn Sound On when starting**: when this is on, sound is on by itself every time the panel opens and every time a Schema is loaded, so you do not have to click the **Sound** icon. Press **Save** to keep it.

Browsers (Chrome, Edge, Safari, iPhone and Android) do not let a page play any sound until you tap or click it once. So when the panel opens, the button at the top says **Sound on (tap anywhere)**: tap or click anywhere on the page once and the sound plays from then on. An alarm that went off before that first tap starts as soon as you tap.

**Order of the Menu** (in ☰ Menu > Default settings): each Menu tab has an Order number. Type a new number to move a Menu tab there. The others are numbered again to make room (1, 2, 3 ...), and the Menu and the open Menu tabs sort themselves. New Menu tabs added later go at the end.

## The other Menu tabs

- **Zoom**: how big the tabs show, and Full screen. See [Zoom and Full screen](41-zoom-and-full-screen).
- **Equipment Profile**: the losses and efficiency, the vessels, and which profile each Tab of the loaded Schema uses. See [Schemas and Equipment Profiles](28-schemas-and-equipment-profiles).
- **Vessel** is gone: the [Equipment Profile Interview](196-equipment-profile-interview) took its place. See [Vessel settings](34-vessel-tab).
- **Vessel Templates**, **Equipment Templates** and **Fitting Templates**: ready-made vessels, chillers, coils, trub filters and Bundled Fittings (Skynet and your own) as small icons. Double-click one for its settings, or put a copy on a Tab. See [Vessel and Fitting Templates](50-vessel-and-fitting-templates).
- **Default Layout**: the vessels and pipes a Tab gets with its Equipment Profile. See [Schemas and Equipment Profiles](28-schemas-and-equipment-profiles).
- **Mash Profile** and **Boil Profile**: see [Mash and Boil Profiles](35-mash-and-boil-profiles).
- **Tab Profile**, **Valve Profile** and **Pump Profile**: see [Tab and Valve Profiles](36-tab-and-valve-profiles).
- **Move Brain** (Admins): move everything to a new Brain, for example from a computer to a Raspberry Pi, then fix the USB ports. See [Move Brain](119-move-brain).
- **Schema**: see [Switching and cloning Schemas](48-schema-switching-and-cloning).
- **About**: see [About and Schema versions](42-about-and-schema-versions).
