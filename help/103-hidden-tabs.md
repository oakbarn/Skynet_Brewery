# Hidden Special Tabs

A **Hidden Tab** is a Special Tab for things a Process uses but nobody needs to see on Brew Day: a `gV_` variable only a Process sets, a helper Widget, a Device you never tap. Think of it as the background.

- **It shows only in Edit layout.** On Brew Day it is not in the Tab bar or the ☰ Menu screen list, but everything on it still works: Processes read and set its Devices, Widgets and variables as usual.
- **Make one:** Edit layout > **👻 Hidden tab**. The first is **Hidden_1**, then **Hidden_2** and so on. You can make as many as you like; each follows the same rules.
- **Its name always starts with `Hidden_`.** Change the part after it in **Tab settings** (for example `Hidden_Mash_Helpers`). If you take `Hidden_` off, it is put back. A Tab you rename to start with `Hidden_` becomes a Hidden Tab too.
- In Edit layout a Hidden Tab's button has a 👻 and a dotted border.
- Leaving Edit layout while a Hidden Tab is open goes to the first Tab you can see.

This is easier than putting things on a normal Tab with **Hidden Locked** on each one.
