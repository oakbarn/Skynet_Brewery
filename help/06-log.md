# Log (the brew database)

The **Log** screen shows values that were written to the brew database (`data/brewlog.db` on the Pi).

1. Pick a name, or leave it on all.
2. Set **From** and **To** if you want a time span, and **Max** rows.
3. Press **Show**.
4. **Download CSV** gives the same rows as a file for Excel or Google Sheets.

What gets written, and when, is set per variable with its **database trigger**: see [Variables](04-variables). Only vAPI variables and Globals can be logged.
