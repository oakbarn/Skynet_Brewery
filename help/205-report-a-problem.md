# Report a Problem

Found something that does not work, or a better French wording for a Help page? Report it with **🐞 Report a problem**.
You do not need to know anything about programs: you answer a few plain questions, in your own words.

## Where to find it {#where}

- **☰ Menu > 🐞 Report a Bug** (everyone)
- **☰ Menu > About > 🐞 Report a problem**
- **🐞 Report** at the top of every Help page (next to 🖨 Print). From a Help page, the page's name is filled in for you.

## Pick what it is {#pick}

| Kind | When |
|---|---|
| **🐞 A bug** | Something did not work, or did something you did not expect. |
| **🌐 The French Help** | A better French wording for a Help page (written in English and French). |

Then press **GitHub** or **✉ Email**:

- **GitHub** opens a short form on Skynet's GitHub (github.com/oakbarn), with your **Skynet version**, the **page** and your **computer and
  browser** already filled in. GitHub needs a free sign-in.
- **✉ Email** opens your own mail program with the same questions and details filled in, to **support@oakbarnbrewery.com**. No
  GitHub sign-in needed.

Nothing is sent until you press Send (on GitHub, **Create**).

## Tips for a good report {#tips}

- Say what you saw, word for word if a message popped up.
- List what you did just before it went wrong, one step per line.
- Add a picture of the screen: on GitHub, drag it into the **Pictures** box or paste it; in an email, attach it.
- One problem per report.

## French Help corrections {#french}

The French Help was translated by a machine, so better wordings are very welcome. Read the page in **🌐 Français**, then press
**🐞 Report**: the French form is the one lit up. Copy the sentence as it is now, then write how it should read.
The names of buttons, boxes and menus stay in English on purpose, exactly as they are on the screen (**Finish Build**), so leave
those in English.
