# Help in its own window

Help opens in a **window of its own**, so you can read the steps in one window and do them on the Brew Panel in the other, without jumping back and forth.

## Opening Help

- The yellow **?** on the Tabs bar, right next to **☰ Menu**, opens Help on the Tabs page. When a ☰ Menu tab is open (Default, Vessel, Schema ...) it opens the Help for that Menu tab.
- **Help** on the Menu Bar, and **Help** in the ☰ Menu's list of Pages, open the Help for the page you are on.
- A **right-click** on an item, and every yellow **?**, open Help at the part about that item (see [Right-click and ? for Help](43-right-click-help)).

There is only ever **one** Help window. Asking for Help again shows the new page in the same window and brings it to the front, so windows don't pile up.

## Putting it beside the panel

On a PC or Mac the Help window opens on the right side of the screen. Move or size it like any window. A handy setup is the panel on the left half of the screen and Help on the right half. On Windows you can drag a window to the left or right edge of the screen to make it fill that half.

The Help window has its own search, page list, **◀ Back**, **🖨 Print** and, for admins, **✏ Edit page**. **Close** closes the Help window.

## On a phone or tablet

Phones and tablets open Help as a **new browser tab** instead of a window. Switch between the panel and Help with the browser's tab button.

Holding a finger on an item opens Help **on the panel's own Help page**, because browsers never let a long press open a new tab. Its **Close** button takes you back.

## If the Help window doesn't open

Some browsers block windows a page opens ("pop-ups"). Then Help shows on the panel's own Help page as before, and a message says the window was blocked. To get the window, allow pop-ups for the panel:

- **Chrome and Edge**: click the blocked pop-up icon at the right end of the address bar and pick **Always allow pop-ups** for the panel.
- **Firefox**: click **Options** on the yellow bar under the address bar and pick **Allow pop-ups**.
- **Safari on a Mac**: Safari > Settings > Websites > Pop-up Windows, and set the panel to **Allow**.
