# Raccourcis clavier {#shortcut-keys}

Ces touches marchent dans **chaque case de texte** de Skynet Brewer : fenêtres Properties, Labels, Texts, Names, les fenêtres
String Entry (la flèche rouge ⬆, Règle 18.1), l'éditeur de Process et Schema.json. (Règle 2.32)

## Touches Skynet {#skynet-keys}

| Windows et Linux | Mac | Ce qu'elle fait |
|---|---|---|
| **Maj + Entrée** | **Maj + Entrée** | Tape `\n`, le code de nouvelle ligne. Le texte passe à la ligne là où il est affiché. |
| **Ctrl + B** | **⌘ + B** | Gras. Avec des mots choisis, met `\b` avant et après eux. Sans rien de choisi, tape `\b\b` avec le curseur entre les deux, pour que vous y tapiez les mots en gras. |
| **Ctrl + Maj + D** | **⌘ + Maj + D** | Tape **°F** ou **°C**, selon le réglage **Temperatures** du Tab ☰ Menu > **Default**. |

`\n` et `\b` sont des Rich Text Embedded Codes : voir [Les zones de texte](49-text-boxes) et [Le langage des Processes et les étapes](22-process-language).
Tout ce que tapent ces touches peut être annulé avec Annuler, comme toute autre frappe.

## Touches courantes {#common-keys}

| | Windows et Linux | Mac |
|---|---|---|
| Copier | Ctrl + C | ⌘ + C |
| Couper | Ctrl + X | ⌘ + X |
| Coller | Ctrl + V | ⌘ + V |
| Coller en texte simple | Ctrl + Maj + V | ⌘ + Maj + V |
| Annuler | Ctrl + Z | ⌘ + Z |
| Rétablir | Ctrl + Maj + Z ou Ctrl + Y | ⌘ + Maj + Z ou ⌘ + Y |

- Chaque case de texte Skynet contient du texte simple, donc un Coller normal est déjà du texte simple. Safari n'a pas de ⌘ + Maj + V à lui,
  donc Skynet le fait là (Safari peut montrer d'abord un petit bouton **Coller** à toucher).
- **Ctrl + Y / ⌘ + Y** est Rétablir dans une case de texte. Hors d'une case de texte, le navigateur garde son propre usage (sur un Mac, ⌘ + Y
  ouvre l'Historique).
- **Entrée** seule fait toujours ce qu'elle faisait avant (dans une case d'une ligne, elle appuie souvent sur OK ou Save).
- Les téléphones et tablettes sans clavier n'ont pas ces touches ; tapez `\n` et `\b` à la main.
