# La barre de menus (Menu Bar) {#the-menu-bar}

La **Menu Bar** est la ligne du haut du panel : le nom du panel, le sélecteur **Schema**, les boutons des pages (Tabs, Processes, Variables, Log, Devices, Media, Import, Settings, Help ...), **Enable sound** et **Sign out**.

## Cachée sur chaque Tab {#hidden-on-every-tab}

Quand l'un de vos Tabs est affiché, la Menu Bar est cachée, pour laisser la place au Tab. C'est pratique sur un téléphone.

Seuls vos Tabs la cachent. Chaque onglet du **☰ Menu** (Zoom, Default, Equipment Profile, Schema, About ...) et chaque autre page (Processes, Log, Settings, Help ...) montre toujours la Menu Bar.

- Appuyez sur **☰ Menu** (en haut à droite) et choisissez **▼ Show Menu Bar** pour la faire revenir.
- Appuyez sur **☰ Menu** et choisissez **▲ Hide Menu Bar** pour la cacher de nouveau.
- Aller sur un onglet du ☰ Menu ou une autre page (Processes, Log, Settings ...) y montre la Menu Bar. Quand vous revenez à un Tab, elle est de nouveau cachée.
- En **Full screen** (plein écran), la Menu Bar reste aussi cachée. Appuyez sur Échap ou sur **Exit full screen** pour quitter le plein écran.

## Toujours montrer la Menu Bar {#always-showing-the-menu-bar}

Un Admin peut le couper dans **Settings > Panel settings: screen, Tabs and alerts** : sous **Menu Bar**, éteignez **Hide the Menu Bar on Tabs** et appuyez sur **Save**. La Menu Bar s'affiche alors toujours, et le ☰ Menu n'a plus de choix Show / Hide Menu Bar.

## Les sons d'alarme {#alarm-sounds}

Les navigateurs ne jouent les sons qu'après que vous avez appuyé une fois sur **Enable sound**. Il est dans la Menu Bar, donc choisissez d'abord **☰ Menu > Show Menu Bar**, puis appuyez sur Enable sound.
