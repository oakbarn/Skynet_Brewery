# Patron {#patron}

Skynet est gratuit. Un **Patron** (mécène) aide à le financer et reçoit quelques avantages en plus (Règle Skynet 12.4).

## Ce que reçoit un Patron {#what-a-patron-gets}

**Patron : 10 $ tous les 6 mois**

- **Request a Feature** (demander une fonction) : demandez une nouvelle fonction à l'équipe OakBarn Brewery, directement depuis **☰ Menu > ⭐ Request a Feature**.
- **Alerte e-mail pour les nouvelles versions** : un e-mail quand un nouveau Skynet sort. Vous vous inscrivez sur oakbarnbrewery.com ; c'est OakBarn Brewery qui l'envoie, jamais votre Brain.
- **Envoyer votre pompe à OakBarn Brewery** (à venir) : une pompe que vous avez faite peut devenir une pompe Skynet que tous les brasseurs reçoivent.
- **Le nom de votre brasserie** : le nom tapé dans **☰ Menu > Default settings > Brewery Name** (vide : le nom inscrit sur votre code Patron) s'affiche sur la Menu Bar de chaque Tab et dans l'éditeur de Processes, et chaque nouveau Process indique **Created by** avec le nom de votre brasserie et **Copyright ©** avec ce nom. Sans être Patron : la Menu Bar affiche **Skynet Panel**, la case Brewery Name est grisée (ce que vous avez tapé est gardé), et un nouveau Process indique **Copyright ©** et l'année.

Les niveaux et les avantages peuvent changer selon ce qu'OakBarn Brewery observe.

## Votre code Patron {#your-patron-code}

Quand vous devenez Patron, OakBarn Brewery vous envoie par e-mail un **code Patron**. Il commence par `SKYPATRON1.` et tient sur une longue ligne.

1. Ouvrez **Settings > Patron** (un Admin).
2. Collez le code entier dans **Patron code** et touchez **Save Patron code**.
3. **Settings > Patron** affiche maintenant ⭐ **Patron** et la date de fin, et les avantages sont débloqués jusqu'à ce jour.

Un renouvellement ? Collez le nouveau code de la même façon. **Remove Patron code** verrouille à nouveau les avantages.

Votre Brain vérifie que le code vient vraiment d'OakBarn Brewery : un code inventé, ou avec une seule lettre changée, est refusé.

## Votre adresse e-mail reste chez vous {#your-email-address-stays-with-you}

Un code Patron ne contient que le nom à afficher, le niveau et la date de fin : **jamais d'adresse e-mail**. Les e-mails aux Patrons sont envoyés par OakBarn Brewery en dehors de Skynet, donc votre Brain ne les garde jamais. OakBarn Brewery ne vend ni ne partage jamais une adresse e-mail, n'envoie jamais de spam, et **ne vous envoie jamais d'e-mail au sujet de votre mot de passe** (voir [Connexion, utilisateurs et mots de passe](10-login)).

## Request a Feature {#request-a-feature}

**☰ Menu > ⭐ Request a Feature** : tapez un titre court et ce que la fonction doit faire, puis touchez **Send to OakBarn Brewery**.

- Si votre Brain envoie des e-mails (**Settings > Sending codes**), la demande part de votre propre compte e-mail vers support@oakbarnbrewery.com.
- Sinon, votre propre programme de messagerie s'ouvre avec la demande déjà remplie : appuyez sur **Send** là-bas.

Pas encore Patron ? Il montre ce que sont les avantages Patron, avec un lien vers oakbarnbrewery.com.
