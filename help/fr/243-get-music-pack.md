# Obtenir le Music Pack {#get-music-pack}

Le **Skynet Music Pack** est un ensemble de marches et de sonneries de clairon du domaine public, par exemple **First Call**, **Mail Call**, **Taps**, **Semper Fidelis** et **The Stars and Stripes Forever**. Utilisez-les dans une Alarme, un Audio Widget ou un Process comme n'importe quel autre son.

Il n'est **pas** dans les Setups, donc les Setups restent petits. **☰ Menu > Get Music Pack** le copie sur votre Brain, dans `media/sounds/Skynet_Music`.

- Ça marche pareil sur un Raspberry Pi, Windows, Mac ou Linux. Rien à installer : c'est le Brain qui télécharge.
- **Aucun compte GitHub n'est nécessaire.** Le Brain doit seulement être sur Internet.
- **Un son que vous avez déjà n'est jamais changé, vos propres sons ne sont jamais touchés, et rien n'est jamais supprimé.**
- Admins seulement.

## Comment s'en servir {#how-to-use-it}

1. Ouvrez **☰ Menu > Get Music Pack**. Il interroge GitHub tout de suite.
2. Vous voyez combien de sons le pack contient, et la liste de ceux que ce Brain n'a pas encore, avec leur taille.
3. Appuyez sur **Get N sounds**. Quand c'est fini, les nouveaux sons sont dans chaque liste de sons.

Appuyez sur **Check GitHub** pour redemander. Si tout est déjà là, il dit **Nothing to get** (rien à obtenir).

## Bon à savoir {#good-to-know}

- Chaque son est vérifié avec la taille et l'empreinte de GitHub avant d'être enregistré, donc un téléchargement raté n'arrive jamais. Si l'un échoue, il est listé avec la raison ; appuyez sur **Check GitHub** et obtenez-le à nouveau.
- Les sons du Music Pack sont des fichiers son ordinaires. Vous pouvez en copier un, le renommer ou l'utiliser comme votre propre son.
- Si GitHub dit **too many requests** (trop de demandes), attendez une heure.
- Les sons qui viennent avec Skynet lui-même sont dans [Les images et sons Skynet](183-skynet-media-setup). Qui a fait chaque morceau est dans les Media credits du README de Skynet.
