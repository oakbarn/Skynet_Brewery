# Le ☰ Menu partout {#the-menu-everywhere}

Le bouton **☰ Menu** n'est pas seulement sur la page des Tabs. C'est un moyen de circuler depuis presque partout :

- **Les fenêtres qui s'ouvrent** (Properties, régler une valeur ou une minuterie, Find, la Corbeille, les sauvegardes, les avertissements ...) ont un petit bouton **☰** dans leur coin en haut à droite.
- **Toutes les autres pages** (Processes, Variables, Log, Devices, Media, File Move, Import, Settings, Help, Schema.json) ont un bouton **☰ Menu** sur la Menu Bar, à côté de Enable sound.
- Sur la page des **Tabs** et sur les **Menu tabs**, il reste où il a toujours été, au bout droit de la ligne des onglets.

## Ce qu'il contient {#what-is-in-it}

Les mêmes choix que le ☰ Menu de la page des Tabs (voir [Le ☰ Menu](33-menu)) : **Edit layout** (Admins), puis les Menu tabs dans leur ordre (Zoom, Default, Equipment Profile, Vessel, Schema, About ...).

Chaque ☰ (aussi celui de la page des Tabs) liste aussi les **Pages** à la fin : Tabs, Processes, Variables, Log et le reste de la Menu Bar, et sous chaque page ses parties (vos Tabs d'écran, Interfaces (cartes), Users, MQTT and voice ...). La page où vous êtes est en gras. Ainsi vous pouvez aller partout même quand la Menu Bar est cachée derrière une fenêtre. Voir [Chaque écran dans le ☰ Menu](67-every-screen-in-the-menu).

## Quitter une fenêtre {#leaving-a-window}

Choisir un élément du ☰ dans une fenêtre ferme d'abord cette fenêtre, comme si vous appuyiez sur **Cancel**, puis vous y emmène.

- Si vous avez changé quelque chose dans la fenêtre sans l'enregistrer, le panel demande d'abord : **This window has changes that are not saved. Leave them?** (Cette fenêtre a des changements non enregistrés. Les abandonner ?) Appuyez sur Cancel pour rester et enregistrer.
- **Mode construction :** pendant que vous êtes en **Edit layout**, le bouton **☰ Menu** lui-même est grisé, et les fenêtres qui s'ouvrent n'ont pas de ☰, car rien dedans ne marche pendant que vous construisez. Appuyez sur **Exit** ou **Save layout** dans la barre Edit layout pour quitter Edit layout d'abord. Pendant qu'une fenêtre est ouverte, toute la barre Edit layout au-dessus du Tab est grisée aussi : terminez la fenêtre ou appuyez sur Cancel pour la retrouver (Skynet Rule 2.52).

## Les fenêtres sans ☰ {#windows-without-the}

Quelques fenêtres demandent une réponse avant d'aller ailleurs, elles n'ont donc pas de ☰ :

- **✋ Manual valve** : un Process attend que vous ouvriez ou fermiez une vanne à la main et que vous appuyiez sur Done. Voir [Vannes manuelles](29-manual-valves).
- La fenêtre du **code de récupération** après la création d'un Admin. Notez d'abord le code. Voir [Connexion, utilisateurs et mots de passe](10-login).
- La fenêtre **Welcome** qui demande de quel Schema exemple partir.
- La fenêtre **🍺 Beer money**.
