# La New Schema Interview {#the-new-schema-interview}

Dès que **Add new Schema** a fait votre nouveau Schema et l'a chargé, la **New Schema Interview** s'ouvre. Elle pose quelques courtes questions sur le nouveau Schema, une page à la fois. Les étapes sont listées en haut, pour que vous voyiez toujours où vous en êtes.

- **Next ▶** garde une réponse telle quelle et continue. **◀ Back** revient d'une page.
- **Rien n'est changé avant ✔ Finish.**
- **Close** (ou **✕**) arrête l'interview. Le nouveau Schema reste tel qu'il a été fait ; vous pouvez tout changer plus tard.
- **✔ Finish** et **Close** vous emmènent au premier Tab du nouveau Schema, pas de retour à la page Schema.

## Les pages {#the-pages}

1. **About** : le **Name** (déjà rempli) et **What is it for?** (à quoi il sert), une ligne comme *Keg Cleaning* ou *Hot Side, 10 gallon*. Elle s'affiche dans la liste des Schemas de l'onglet **☰ Menu > Schema**. Vous pouvez la laisser vide.
2. **Boards** : les cartes (Interfaces) du nouveau Schema, et les vraies cartes de vos autres Schemas. Cochez chacune que ce Schema utilise aussi. Pour ajouter une carte qu'aucun Schema n'a encore, activez **➕ Add a New board after Finish** (ajouter une nouvelle carte après Finish) : après **✔ Finish** la fenêtre **Add Interface** s'ouvre, et après son **Save** la page des Interfaces montre la nouvelle carte. Voir [Interfaces](76-interfaces).
3. **Tabs** : une case pour chaque Tab, et **➕ Add New Tab** (ajouter un Tab) pour un autre. Dans chaque case :
   - **Tab name** (nom du Tab, par exemple *Main* en *Brew House*).
   - **What is it for?** (à quoi il sert) : **Brewing (Brew House)** (brassage), **Fermentation**, **Cleaning** (nettoyage), ou **Other** (autre : un Tab à vous, nommé dans Tab name).
   - **Level** (niveau, Brewing seulement) : comment vous brassez sur ce Tab, de **Stove Top (Extract)** (sur la cuisinière, extrait) à **All Grain with Mash Tun (3 Vessels)** (tout grain avec cuve d'empâtage, 3 cuves). Il commence sur votre **Skynet Brewer Level**, le niveau choisi la dernière fois (All Grain with Mash Tun la première fois).
   - **Equipment Profile** : **None** (aucun ; ajoutez-en un plus tard dans **☰ Menu > Equipment Profile**), **➕ Create New** (créer : l'Equipment Profile Interview s'ouvre après Finish, voir [L'Equipment Profile Interview](196-equipment-profile-interview)), ou un profil que vous avez déjà. Seuls les profils pour ce à quoi sert le Tab sont listés. Autant de Tabs que vous voulez peuvent commencer à partir du même profil.
   - **Import** (avec un profil que vous avez) : **Import All** (tout) met une copie de tout le Default Layout du profil sur le Tab. **Import Vessels** (les cuves) met seulement ses cuves et son équipement, avec leurs raccords. **Import Manifold** (le collecteur) met seulement les vannes, raccords et tuyaux entre les cuves. Les nombres du profil sont copiés aussi. Ensuite le Tab ne garde aucun lien avec le profil : un changement sur l'un ne change jamais l'autre.
   - **Import Processes** : une coche pour chaque Process Skynet de ce genre et de ce niveau (un Stove Top n'a pas de Mash). Ceux qui sont cochés sont réglés dans **☰ Menu > Brew Process** ; un Process non coché est laissé de côté.
4. **Done** : ce qui sera gardé. Appuyez sur **✔ Finish**.

**Un Skynet Schema Template** ou **un Equipment Profile** a déjà posé les questions sur les cartes, les Tabs et l'équipement, donc ils n'ont que **About** et **Done**.

Les unités (US ou Metric) ne sont pas demandées : c'est un réglage du Panel, le même pour chaque Schema (**☰ Menu > Default settings**).
