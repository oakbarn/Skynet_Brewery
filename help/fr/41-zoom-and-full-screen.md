# Zoom et plein écran {#zoom-and-full-screen}

Zoom et Full screen sont dans l'onglet de menu **☰ Menu > Zoom**. Ils ne sont plus sur la barre des Tabs. Zoom est le numéro 1 du ☰ Menu au départ ; vous pouvez le déplacer sur l'onglet de menu **Default** (Order of the Menu), comme n'importe quel autre onglet de menu.

## Zoom

Appuyez sur l'une des tailles. Le panel revient tout de suite à votre Tab à cette taille.

- **Fit screen** : tout le Tab tient sur votre écran.
- **Fit width** : le Tab remplit la largeur de votre écran ; faites défiler vers le bas pour le reste.
- **50 %** à **150 %** : des tailles fixes.

Chaque navigateur se souvient du dernier zoom choisi.

## Plein écran {#full-screen}

**Full screen** cache les barres du navigateur et la Menu Bar, pour que le Tab ait tout l'écran. Appuyez sur **Échap** (ou ☰ Menu > Zoom > **Exit full screen**) pour les faire revenir.

Les iPhones ne peuvent pas passer en plein écran dans un navigateur. Sur un iPhone, utilisez **Partager > Sur l'écran d'accueil** (Share > Add to Home Screen) dans Safari : le panel s'ouvre alors depuis sa propre icône sans les barres du navigateur.

## Ce avec quoi le panel démarre {#what-the-panel-starts-with}

Sur l'onglet de menu **Default**, sous **On startup** (Admins) :

- **Zoom** : la taille avec laquelle chaque navigateur démarre. **(the last one used on this browser)** (le dernier utilisé sur ce navigateur) garde le choix propre à chaque navigateur.
- **Full screen** : allumez-le pour démarrer en plein écran. Les navigateurs n'autorisent le plein écran qu'après un clic ou un toucher sur la page, donc le panel passe en plein écran à votre **premier clic ou toucher**. Cela ne fait rien sur les iPhones.

Appuyez sur **Save** sur l'onglet Default.
