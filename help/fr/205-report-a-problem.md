# Signaler un problème {#report-a-problem}

Vous avez trouvé quelque chose qui ne marche pas, ou une meilleure traduction pour une page d'aide en français ? Signalez-le
avec **🐞 Report a problem**. Pas besoin de connaître la programmation : vous répondez à quelques questions simples, avec vos
propres mots.

## Où le trouver {#where}

- **☰ Menu > 🐞 Report a Bug** (tout le monde)
- **☰ Menu > About > 🐞 Report a problem**
- **🐞 Report** en haut de chaque page d'aide (à côté de 🖨 Print). Depuis une page d'aide, le nom de la page est rempli pour vous.

## Choisissez de quoi il s'agit {#pick}

| Type | Quand |
|---|---|
| **🐞 A bug** | Quelque chose n'a pas marché, ou a fait ce que vous n'attendiez pas. |
| **🌐 The French Help** | Une meilleure traduction pour une page d'aide (formulaire en anglais et en français). |

Appuyez ensuite sur **GitHub** ou **✉ Email** :

- **GitHub** ouvre un court formulaire sur le GitHub de Skynet (github.com/oakbarn), avec votre **version de Skynet**, la **page** et votre
  **ordinateur et navigateur** déjà remplis. GitHub demande une connexion gratuite.
- **✉ Email** ouvre votre propre messagerie avec les mêmes questions et détails remplis, vers **support@oakbarnbrewery.com**. Pas
  besoin de connexion GitHub.

Rien n'est envoyé avant que vous appuyiez sur Envoyer (sur GitHub, **Create**).

## Conseils pour un bon signalement {#tips}

- Dites ce que vous avez vu, mot pour mot si un message est apparu.
- Listez ce que vous avez fait juste avant, une étape par ligne.
- Ajoutez une image de l'écran : sur GitHub, glissez-la dans la case **Pictures** ou collez-la ; dans un e-mail, joignez-la.
- Un seul problème par signalement.

## Corrections de l'aide en français {#french}

L'aide en français a été traduite par une machine : les meilleures formulations sont donc les bienvenues. Lisez la page en
**🌐 Français**, puis appuyez sur **🐞 Report** : le formulaire français est celui qui est mis en évidence. Copiez la phrase telle
qu'elle est, puis écrivez comment elle devrait se lire.
Les noms des boutons, des cases et des menus restent en anglais exprès, tels qu'ils sont à l'écran (**Finish Build**) : laissez-les
en anglais.
