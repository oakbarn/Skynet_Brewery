# La fenêtre « argent pour la bière » {#beer-money-pop-up}

Environ une fois par mois, chaque téléphone ou ordinateur affiche une petite fenêtre qui demande quelques dollars pour offrir une bière aux personnes qui construisent le panel. Elle ne s'affiche jamais pendant qu'un Process tourne (sauf ceux qui démarrent avec le serveur), pendant que vous modifiez un Tab, ni par-dessus une autre fenêtre.

Les boutons :

- Le bouton **bière** ouvre PayPal. Les dons vont sur le compte PayPal de Skynet Brewery ; c'est intégré et ne peut pas être changé.
- **Maybe later** (peut-être plus tard) redemande après l'attente habituelle.
- **Already donated** (déjà donné) attend plus longtemps avant de redemander.

Un Admin peut la changer dans **Settings > Beer money pop-up** : l'éteindre, changer le message ou le texte du bouton, régler le nombre de jours entre deux fenêtres, et toucher **Show it now** pour la voir.
