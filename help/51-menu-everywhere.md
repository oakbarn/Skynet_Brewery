# The ☰ Menu everywhere

The **☰ Menu** button is not only on the Tabs page. It is a way to get around from almost anywhere:

- **Windows that pop up** (Properties, setting a value or a timer, Find, the Recycle bin, backups, warnings ...) have a small **☰** button in their top right corner.
- **Every other page** (Processes, Variables, Log, Devices, Media, File Move, Import, Settings, Help, Schema.json) has a **☰ Menu** button on the Menu Bar, beside Enable sound.
- On the **Tabs** page and the **Menu tabs** it stays where it always was, at the right end of the tab line.

## What is in it

The same choices as the ☰ Menu on the Tabs page (see [The ☰ Menu](33-menu)): **Edit layout** (Admins), then the Menu tabs in their order (Zoom, Default, Equipment Profile, Vessel, Schema, About ...).

Every ☰ (on the Tabs page too) also lists the **Pages** at the end: Tabs, Processes, Variables, Log and the rest of the Menu Bar, and under each page its parts (your screen Tabs, Interfaces (boards), Users, MQTT and voice ...). The page you are on is shown in bold. That way you can get anywhere even when the Menu Bar is hidden behind a window. See [Every screen in the ☰ Menu](67-every-screen-in-the-menu).

## Leaving a window

Picking a choice from the ☰ in a window closes that window first, the same as pressing **Cancel**, and then takes you there.

- If you changed something in the window and did not save it, the panel asks first: **This window has changes that are not saved. Leave them?** Press Cancel to stay and save.
- While you are in **Edit layout**, the Menu tabs are greyed out (the note says *Save or exit Edit layout to open a Menu tab*). The pages and **Exit Edit layout** still work.

## Windows without the ☰

A few windows must be answered before you go anywhere, so they have no ☰:

- **✋ Manual valve**: a Process is waiting for you to open or close a valve by hand and press Done. See [Manual valves](29-manual-valves).
- The **recovery code** window after setting up an Admin. Write the code down first. See [Login](10-login).
- The **Welcome** window that asks which sample Schema to start from.
- The **🍺 Beer money** window.
