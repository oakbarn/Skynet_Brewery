Save your recovery code

This code is the only way back in if you forget your password. It is shown only now.

If you forget your password:
  1. On the sign-in page, tap Forgot password?
  2. Type your user name, this code and a new password.
  3. You get a new code. Save that one too (each code works once).
This works from your home WiFi or Tailscale. An admin can make a new code any time in Settings > Recovery code.
