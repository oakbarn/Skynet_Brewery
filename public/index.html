      OneWire probe index
      
    
      Each DS18B20 probe gets a number here, and temperature elements use that number. To replace a probe, plug in the new one and pick its ROM id in the probe's row: every element that uses that number follows it, nothing else changes.
      
    
      #NameProbe ROM idReadingUsed by
      
    
      
    
      OneWire probes seen

      BeerSmith recipe
      
    
      In BeerSmith: File > Export > BeerXML, then choose the .xml file here. Values go into the variables named in Settings > BeerXML mapping.
      
    
    
    
      
    
      Other programs (Node-RED etc.) can POST the XML to /api/import/beerxml.
      

    
      
    
      BruControl configuration
      
    
      Choose a BruControl configuration file (.brucfg, in Documents\BruControl). Its interfaces, device elements, tabs (BruControl workspaces), elements and scripts are brought in with their settings: pins, calibrations, PID / hysteresis / duty cycle settings, timers, alarm sounds, pictures, colors, fonts and positions.

      Start from a sample
      
      
      Each sample is a whole brewery: tabs, pumps, valves, pipes, temperature probes, timers, alarms and starter scripts. Every board is on the simulator until you pick real hardware on the Devices page. Loading one replaces your tabs, elements and devices; a copy of your current setup is saved in config/backups first.
      
      
      
    
      
    
      My account
      
    
      
      
      
      
      
    
      
    
      Sign-in codes by email or text
      
    
      Instead of a password you can tap Email or text me a code on the sign-in page. The code goes to the email address and/or mobile number here.
      
    
      
      
      
      
      
      
    
      
    
      
    
      
      
      Users
      
      
      Admin: everything. Operator: brew day use (switch outputs, set values, start and stop scripts) but no layout, script, device or settings changes. Viewer: watch only.
      
      
      UserRole
      
      
      
        
        
        
        
      
      
      
      Recovery code
      
      
      For a forgotten password: on the sign-in page, Forgot password? takes a user name, this code and a new password. It only works from your home WiFi or Tailscale, and each code works once. Forgot a helper's password? Use Set password above instead.
      
      
      
      
      Write this down now and keep it away from the Pi. It is shown only this once. Any older code no longer works.
      
      
      Sending codes (email and text)
      
      
      The panel sends sign-in codes from your own email account. Texts are sent free through your phone carrier's email-to-text address, or through Twilio (a paid service, about a cent per text, works with every carrier). Passwords here are kept on the Pi only.
      
      
      
        
        
      
      
      
      
        
        
        
      
      
      
      
        
        
        
      
      
      
      Gmail: turn on 2-Step Verification, then make an app password at myaccount.google.com/apppasswords and paste it above (not your normal Gmail password).
      
      
      
        
        
        
      
      
      
      
      
      Testing mode
      
      
      
      While this is on, installing a new version of the panel removes every user and recovery code, so the next visit asks you to create the admin account again. Brew data, logs and settings are kept. Turn it off once you use the panel for real.

      Pictures (PNG / JPG to SVG)
      
      
      Every PNG or JPG put in a media folder gets an SVG copy next to it, so it stays sharp at any size. The original file is never changed, so BruControl can still use it. Tracing works best on drawings and icons; photo-like pictures come out blotchy, so check them here.
