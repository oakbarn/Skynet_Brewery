# Skynet Keys Available

The key combinations Skynet may still give a job to, on **Windows, Mac, Linux and the Raspberry Pi** (Skynet Rule 2.73).
OakBarn Brewery, 2026-11-24: "Give me a second MD of list the keys that are available on Skynet".

Taken from the full table, [Skynet_Key_Combinations.md](Skynet_Key_Combinations.md), where every combination has its reasons. A key never works while typing in a text box.

On Windows, a PC with two keyboard languages switches language when Shift + Alt is pressed alone; with a letter in between it does not.

## Usable by the key's place (10)

The key shows a different sign on European keyboards, so Help names it by where it sits. Use the free ones first.

| Combination | Where the key sits |
|---|---|
| **Alt + -** | the key right of 0 |
| **Alt + =** | the key left of Backspace |
| **Alt + [** | the key right of P |
| **Alt + ]** | the key right of [ |
| **Alt + \** | the key above Enter |
| **Alt + ;** | the key right of L |
| **Alt + '** | the key right of ; |
| **Alt + ,** | the key right of M |
| **Alt + .** | the key right of , |
| **Alt + /** | the key left of right Shift |

## Already used by Skynet (23)

| Combination | What it does |
|---|---|
| **Alt + P** | Picture picker (admins, Rule 18) |
| **Ctrl + left click  (⌘ + click)** | Opens Properties in Edit layout (Rule 2.9) |
| **Shift + right click** | Browser menu instead of Help (Rule 2.11) |
| **Right click** | Help for what is under the mouse (Rule 2.11); never drags (Rule 2.9) |
| **Left hold (0.4 s) then drag** | Moves a QD hose end, chiller or Template icon outside Edit layout (Rule 2.9) |
| **Double-click** | Opens Properties in Edit layout; finishes a hose |
| **Z** | Zoom box on / off (Edit layout, Rule 5.37) |
| **R / Shift + R** | Turns the picked fitting a quarter turn right / left (Edit layout, Rule 5.5) |
| **H** | Flips the picked fitting left to right (Edit layout, Rule 5.5) |
| **V** | Flips the picked fitting top to bottom (Edit layout, Rule 5.5) |
| **Ctrl + Z  (⌘ + Z)** | Put back the last move (Edit layout); undo typing in a box |
| **Ctrl + Y  (⌘ + Y)** | Redo typing in a box (Rule 2.32) |
| **Ctrl + B  (⌘ + B)** | Bold code \b ... \b in a text box (Rule 2.32) |
| **Ctrl + Shift + D  (⌘ + Shift + D)** | Types °F or °C in a text box (Rule 2.32) |
| **Shift + Enter** | Types the new line code \n in a text box (Rule 2.32) |
| **Ctrl + S  (⌘ + S)** | Save in the Process editor and the Schema editor |
| **Ctrl + F  (⌘ + F)** | Find bar |
| **Ctrl + H** | Replace bar |
| **Delete / Backspace** | Delete the picked item (Edit layout, Rule 2.64) |
| **B / Insert / Right Arrow** | Copy of the focused Template onto the 🔨 Build Tab (Rule 4.10) |
| **Enter** | Opens a focused Template; Save / next box in dialogs |
| **Esc** | Closes the Zoom box, pop-ups and dialogs |
| **Alt + left click / drag** | Hold Alt while dragging = place without the snap (Edit layout) (may not reach the Panel on a Pi) |
