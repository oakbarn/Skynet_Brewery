# Existing gGlobals

Every gGlobal in the Schemas Skynet ships: the default Schema and the sample Schemas. The Oakbarn Schema is left out (Fritz, 2026-11-02).
Made on 2026-11-02 for Fritz to sort out: the ones that are true variables with a global scope stay gGlobals; the others become a Text Widget or a Graphic Widget (one at a time, on his word). Switch, Push Button, Pulse Button, List, Step and Long String ones are not gGlobals any more and go to the new Semi_Widgets_Devices class.
